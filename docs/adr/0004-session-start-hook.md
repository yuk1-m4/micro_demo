# 0004. セッション開始時の準備は SessionStart フックで行う

- 日付: 2026-11-24
- 状態: 採用
- 関連: Linear WORK-2

## 背景
クラウド開発環境では、セッション開始時に Docker デーモンが止まっている。
また、git のコミット作成者が `Claude` になっていて、`yuk1-m4` として記録されない。

## 決定
`.claude/hooks/session-start.sh` を SessionStart フックとして登録し、
クラウドのときだけ「git の作成者を `yuk1-m4` に設定」と「Docker デーモンの起動」を行う。
環境のセットアップスクリプト案は、常駐プロセスを起動したままにできないため不採用。

## 結果
- 新しいセッションでも再開時でも、すぐに Docker と正しい作成者で作業できる。
- フックは同期実行なので、セッションの開始が約1秒遅れる。
- ローカルの Mac では何もしない。

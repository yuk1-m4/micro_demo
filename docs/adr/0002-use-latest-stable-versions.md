# 0002. 言語・ツールは最新の安定版を使う

- 日付: 2026-11-24
- 状態: 採用
- 関連: Linear WORK-2

## 背景
特定のバージョンに縛られる理由がない。古い雛形のままでは npm の脆弱性が3件（うち重大2件）残っていた。

## 決定
脆弱性対応を優先し、作成時点の最新の安定版を使う。
Node.js は LTS（26）、nginx は mainline（1.31）、Go は 1.27。
frontend は最新の `create-vite` 雛形で作り直し、lint は雛形に合わせて ESLint から oxlint に変える。

## 結果
- 作成時点で npm の脆弱性は0件。
- メジャーバージョンが上がるたびに設定の書き直しが必要になる。
  そのときは設定を手で直すより、雛形を作り直して差分を戻す方が速い。

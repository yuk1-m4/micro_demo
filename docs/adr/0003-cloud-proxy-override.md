# 0003. クラウド環境用のプロキシ設定は上書きファイルに分ける

- 日付: 2026-11-24
- 状態: 採用
- 関連: Linear WORK-2

## 背景
クラウド開発環境では、コンテナ内から外部への通信がセッションのプロキシ経由になる。
コンテナはプロキシに届かず、その CA 証明書も信頼しないため、ビルド中の `npm ci` が失敗した。

## 決定
`compose.cloud.yaml` を追加し、ビルド時だけホストのネットワーク・プロキシ・CA 証明書を渡す。
CA 証明書は BuildKit の secret で渡し、イメージには残さない。

## 結果
- Dockerfile と `compose.yaml` はローカルとクラウドで共通のまま使える。
- クラウドでは `-f compose.yaml -f compose.cloud.yaml` を付けて実行する必要がある。

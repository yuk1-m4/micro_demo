# 0006. 消費税は税込経理で記帳し、税額の計算と端数処理は扱わない

- 日付: 2026-11-25
- 状態: 採用
- 関連: Linear WORK-4（WORK-12）

## 背景
WORK-4 の調査では、適格請求書の税額の端数処理や内税の逆算まで実装する案が出ていた。
このデモの目的は、貸借対照表と損益計算書を作る簡易な複式簿記で「仕訳の借方と貸方が必ず一致し、丸め誤差が出ない」ことを示すことにある。
消費税をきちんと扱うには、端数処理の方法の選択、税率ごとの集計、申告での割戻し計算と積上げ計算の区別まで必要になり、デモの論点がぼやける。

## 決定
取引は税込経理で記帳する。仮受消費税・仮払消費税の勘定は作らず、税率も端数処理の設定も持たない。
税込経理は正規の会計処理なので、税込金額だけで貸借対照表と損益計算書は作れる。
適格請求書の発行、税抜経理での税額の分割、消費税申告の計算はスコープ外とする。

## 結果
- 金額の計算が整数の加減算だけで済み、丸めが入るのは為替換算などの割り算だけになる。
- 消費税の端数処理や8%・10%の混在を扱える、という実務上の力は示せない。必要になれば新しい ADR で追加する。
- WORK-4 のコメントにある消費税関係の受入条件（10円×8%、内税の逆算など）は実装しない。按分の最大剰余法は為替などで必要になれば使う。
